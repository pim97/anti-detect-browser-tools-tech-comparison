How to read this

Evidence tier, not a score

There are no ratings on this page. Ratings were removed from this project because a five-star grid looked like measurement while being opinion. What replaced them is a record of what each tool does and how that was established. Every claim below carries one of four tiers.

A Verified in source

Read in the code at a stated commit, inside an isolated container. File paths cited.

B Vendor-reported

The maintainer publishes it. Located, quoted, not reproduced here.

C Community-reported

Issue trackers, forums, third-party posts. Directionally useful, individually unreliable.

D Not established

No evidence located in either direction.

Tier D is not a negative finding. It means nobody has published a test — not that the tool failed one. It is drawn hollow, and never the same as “does not implement”, because collapsing those two is the most common way a comparison misleads.
Nothing here was benchmarked against a live anti-bot service. No claim about Cloudflare, DataDome, Kasada, Akamai, PerimeterX or Imperva outcomes exceeds Tier B — including the confident checkmark grids some of these projects publish.

Lineage

Nine tools, fewer independent implementations

Several of these depend on each other. Picking two for redundancy can mean picking the same code twice — if that lineage gets fingerprinted, both fail together. Every edge below was verified in source.

Limits of this page.
  • No anti-bot service benchmark was run; no service claim exceeds Tier B.
  • Nothing was installed, built, or executed. Tier A means the code was read, not run.
  • Closed components (CloakBrowser's binary, XDriver's bundle) cannot be assessed from source.
  • Metric counts are proxies and are reported with their location in the full review.
  • Single reviewer, single pass, shallow clones.
